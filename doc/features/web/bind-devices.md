# 设备绑定页面

用户在 homelib 脚本中定义树状结构的设备对象：

```ts
const 家 = $home('家');

const 主卧 = 家.$scope('主卧');

const 主卧阅读灯 = 主卧.$$device('阅读灯'); // 一组设备

const 主卧阳台 = 主卧.$scope('阳台');

const 主卧阳台灯 = 主卧阳台.$device('灯');
```

并使用一个或多个协议获取相关设备，比如米家：

```json
{
  "家庭 1": {
    "主卧": [
      {
        "did": "1234567890",
        "model": "zhimi.light.mg1"
      },
      {
        "did": "2345678901",
        "model": "zhimi.light.mg1"
      }
    ],
    "主卧阳台": [
      {
        "did": "0987654321",
        "model": "zhimi.light.mg2"
      }
    ]
  }
}
```

设备绑定页面左侧显示 homelib 设备树，右侧显示协议获取的设备列表（注意考虑切换协议，同一个协议也不排除有多份），用户可以将协议设备拖拽到 homelib 设备树中进行绑定。

当拖拽发生时，需要生成一个增量操作，调用 api 完成绑定并获得新的完整绑定信息，再更新前端绑定状态。期间应该有 loading 状态。
